ONE-SHOT IDEMPOTENT HEREDOC BUILD METHOD
Dual-Wi-Fi & SQLite Contention Forensic Explainer

1. SINGLE-SCRIPT HEREDOC MATERIALIZATION
   Every file is written deterministically via single-quoted heredocs
   (cat <<'EOF' > "$TARGET_DIR/..."), preventing unintended shell expansion.

2. IDEMPOTENT RE-RUN BEHAVIOR
   - mkdir -p creates directories safely whether or not they already exist.
   - Full file overwrites keep every file in sync with the single script.
   - Git stages changes and commits only when staged diffs are non-empty.
   - GitHub repo creation checks `gh repo view` first; GitHub Pages uses
     POST and falls back to PUT if already enabled.
   - Playwright results are parsed recursively into README.txt without
     duplicating prior report sections.

3. DUAL-PLANE ARCHITECTURE
   - Static GitHub Pages Plane: Vite + React + Tailwind CSS + Three.js,
     with Copy/Download code blocks and automatic local backend probing.
   - Optional Local Docker Plane: Caddy + FastAPI + SQLite (WAL + FTS5).
